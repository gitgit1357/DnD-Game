# Field Magic Model — v0.64.0

## Purpose
Spellcasting is not combat-only. Healing and curse/affliction cleansing may be used during normal adventuring when combat is not active.

## Rules
- Uses the caster's normal known spells, level requirement, spell-point pool, reagents, and mastery/failure rules.
- Each field cast consumes **10 campaign minutes**.
- Healing targets the hero or any living companion and uses the same per-cast healing cap concept as combat healing.
- Cleanse spells remove one curse or malign magical affliction from the target.
- Field casting itself does not create fame; visibility/attribution rules still govern recognition.

## Initial cleanse paths
- Cleric: **Purifying Litany** (requires Holy Salts).
- Wodewose: **Cleansing Sap**.

## Future extensions
Poison/disease treatment, divination, wards, travel utility, ritual casting, camp blessings, and curse-specific difficulty can build on this same field-casting interface rather than creating separate subsystems.
