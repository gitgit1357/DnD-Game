# Reference Art

This folder is a home for future UI/illustration reference material — it's
currently empty on purpose.

## Why it's empty
During handoff prep, two screenshots were suggested for inclusion here —
both were stock/licensed artwork search results (a Shutterstock stock
illustration and a piece of watermarked artist work, "ihsans art," found via
Vecteezy/Google Images). Neither is something this project has rights to
copy or redistribute, so they weren't added, even as internal-only
reference. That applies to any future find, too: if it's not yours or
licensed to you, it doesn't belong in this repo, even in a folder no player
ever sees — a private reference use doesn't change the rights question.

## What this style direction actually was
For context on what those images were pointing at (useful when briefing a
future artist or generating original concept art): heavy ink linework,
dramatic anatomy, high-contrast grayscale shading (chiaroscuro), and a
mythic-scale confrontation framing — a lone armed warrior against a much
larger beast-humanoid. That's consistent with the Art Direction already
described in `DESIGN_FOUNDATION.md` ("graphic novel style, heavy ink,
grayscale, selective gold accents, cinematic illustrations only for major
moments") — these images were a visual pointer at the same thing already
written down, not new direction.

## Contents log
- `warrior_vs_orc_bard_lull_2panel.png` — added by the person, confirmed
  not copyrighted/stock. Two-panel piece: top panel is a mid-swing sword
  clash between a cloaked warrior and a large tusked orc; bottom panel is
  the same warrior playing a lute, the orc now asleep under a visible
  magic/sleep effect. Good reference for the graphic-novel ink style
  already described below, and specifically useful for combat-scene and
  spell-effect visual language if the UI ever moves toward illustrated
  combat panels instead of the current text/card-based combat screen.

## How to actually populate this folder
- License art you have real rights to (purchase, commission, or use art
  under a license that permits redistribution/reference use) and drop the
  files in directly.
- Or generate original concept art (AI-generated or hand-drawn) — original
  work sidesteps the rights question entirely.
- Either way, note the source/license for each file here so it's clear
  later what's actually usable in the shipped game vs. reference-only.
